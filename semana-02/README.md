# Semana 02 — CSS e Flexbox

> Dando estilo à página e melhorando a organização dos elementos.

## Sobre a atividade

Nesta semana, trabalhei com CSS para personalizar a página HTML criada anteriormente. O foco foi melhorar a aparência do formulário, organizar os elementos e deixar a página mais agradável e fácil de utilizar.

## O que pratiquei

### Estilização com CSS

Utilizei seletores e propriedades CSS para modificar cores, fontes, bordas, espaçamentos e outros detalhes visuais da página.

### Organização com Flexbox

Utilizei `display: flex` para organizar os campos do formulário lado a lado, ajustando o espaçamento entre eles e aproveitando melhor o espaço disponível.

### Responsividade

Adicionei uma regra com `@media` para que os campos fiquem empilhados em telas menores, facilitando a visualização em dispositivos com pouca largura.

### HTML e CSS juntos

Mantive a estrutura HTML separada da apresentação visual, utilizando classes e identificadores para aplicar os estilos nos elementos necessários.

## ▶️ Como executar

1. Abra o arquivo `index.html` no navegador.
2. Confira os estilos aplicados ao formulário.
3. Redimensione a janela para testar a adaptação dos campos em telas menores.

## O que ficou dessa semana?

Aprendi que o CSS vai além de mudar cores e fontes: ele também permite organizar os elementos e adaptar a página a diferentes tamanhos de tela. O Flexbox facilitou a disposição dos campos, enquanto as media queries ajudaram a manter o formulário organizado em dispositivos menores.
