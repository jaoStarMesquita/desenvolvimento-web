# Semana 01 — Introdução ao HTML

> Construindo a primeira página web e conhecendo a estrutura de um documento HTML.

## Sobre a atividade

Nesta semana, comecei a trabalhar com HTML e seus principais elementos, desenvolvendo a estrutura de uma página no formato de blog com um formulário de inscrição.

A atividade foi o primeiro passo para entender como os conteúdos de uma página web são organizados no navegador.

## O que pratiquei

### Estrutura HTML

Utilizei elementos como `html`, `head`, `body` e títulos para definir a estrutura básica de uma página web.

### Textos e conteúdo

Pratiquei o uso de títulos, parágrafos e outros elementos HTML para organizar as informações e facilitar a leitura.

### Formulário de inscrição

Criei campos para receber informações do usuário, utilizando elementos como `form`, `label` e `input`.

### Organização dos elementos

Aprendi a utilizar diferentes tags HTML de acordo com sua finalidade, mantendo o conteúdo organizado e compreensível.

## ▶️ Como executar

1. Abra o arquivo `index.html` no navegador.
2. Confira a estrutura da página e os elementos apresentados.
3. Teste os campos do formulário de inscrição.

## O que ficou dessa semana?

Essa atividade foi uma introdução à criação de páginas web. Com ela, comecei a entender como o HTML organiza os elementos que aparecem no navegador e como os formulários permitem receber informações dos usuários.
