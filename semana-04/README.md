# Semana 04 — Arrays, DOM e Eventos

> Praticando JavaScript e aprendendo a deixar uma página mais interativa.

## Sobre a atividade

Nesta semana, trabalhei com métodos de arrays, manipulação do DOM e eventos em JavaScript. A ideia foi entender como percorrer e filtrar dados, modificar elementos HTML e criar interações com o usuário.

## O que pratiquei

**Arrays**

- `forEach()` — percorrer os elementos e executar uma ação para cada um.
- `map()` — criar um novo array com os valores transformados.
- `filter()` — selecionar os elementos que atendem a uma condição.
- `reduce()` — acumular valores para chegar a um resultado.

**Manipulação do DOM**

Utilizei `querySelector()` e `querySelectorAll()` para selecionar elementos da página. Também pratiquei a criação de elementos com `createElement()`, a inserção com `append()` e a alteração de classes com `classList`.

**Eventos**

Adicionei eventos de clique, passagem do mouse, teclado e envio de formulário. Também implementei o *Event Delegation*, usando um único listener na lista para identificar os itens clicados, inclusive aqueles criados pelo JavaScript.

No formulário, utilizei `preventDefault()` para evitar o recarregamento da página e `trim()` para impedir o cadastro de tarefas vazias.

## ▶️ Como executar

1. Abra o arquivo `index.html` no navegador.
2. Pressione `F12` e acesse a aba **Console**.
3. Teste o botão, digite um nome e adicione tarefas.
4. Clique nos itens da lista para marcar ou desmarcar como concluídos.
