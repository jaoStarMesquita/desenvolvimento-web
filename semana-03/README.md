# Semana 03 — Introdução ao JavaScript

> Primeiros passos com JavaScript: variáveis, funções, condições e repetições.

## Sobre a atividade

Nesta semana, pratiquei os fundamentos de JavaScript por meio de exercícios de lógica de programação. O objetivo foi entender como armazenar informações, trabalhar com funções e utilizar estruturas de decisão e repetição para resolver problemas.

## O que pratiquei

### Variáveis e tipos de dados

Utilizei `let` e `const` para declarar variáveis e conheci tipos de dados como `string`, `number` e `boolean`. Também pratiquei o operador `typeof` para identificar os tipos de valores.

### Funções

Criei funções de diferentes formas, incluindo declarações tradicionais, expressões de função e funções com parâmetros padrão. Também explorei o conceito de *hoisting* e a diferença entre as formas de declarar funções.

### Condicionais

Utilizei `if/else` para verificar condições e `switch` para trabalhar com diferentes possibilidades, como a avaliação de notas e a interpretação das cores de um semáforo.

### Laços de repetição

Pratiquei `for` e `while` para repetir instruções, montar uma tabuada, fazer contagens regressivas e identificar números pares e ímpares.

### Console

Utilizei `console.log()` para visualizar os resultados e acompanhar a execução dos exercícios.

2. Abra o terminal na pasta `semana-03`.
3. Execute o comando:

   ```bash

   ```

4. Confira os resultados exibidos no terminal.

## O que ficou dessa semana?

Os exercícios ajudaram a entender melhor como o JavaScript executa instruções, toma decisões e repete tarefas. Esses conceitos são a base para desenvolver programas mais completos e, posteriormente, trabalhar com páginas interativas e aplicações web.
